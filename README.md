ML Git Lab – Version Control in Machine Learning

This project demonstrates the use of Git Version Control in a Machine Learning workflow.
The repository contains a sample dataset and Python scripts implementing:

Linear Regression model

Decision Tree model (experimental branch)

Git branching, merging, and commit history

Tools Used

Python

Pandas

Scikit-learn

Git & GitHub

Objective

To understand how version control helps manage ML experiments, track code changes, and collaborate efficiently.
